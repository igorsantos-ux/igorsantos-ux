## Sobre

Formado em Gestão Financeira, atuo com automação de rotinas operacionais — tirando
o trabalho manual e repetitivo do caminho para que os dados cheguem prontos a quem
precisa decidir.

Venho da área de negócio, e é daí que vem meu diferencial: entendo o processo antes
de automatizá-lo. Hoje desenvolvo a base técnica com foco em Python e tratamento
de dados.

- **Foco atual:** Python aplicado a automação e manipulação de planilhas
- **Estudando:** estruturas de dados, boas práticas de código e versionamento
- **Aberto a:** oportunidades e colaborações em automação e análise de dados
